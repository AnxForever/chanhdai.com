## 常用术语

| 术语        | 白话解释                           |
| ----------- | ---------------------------------- |
| Client      | 你实际打开的桌面、编辑器或终端程序 |
| Provider    | 一套服务商连接配置                 |
| Base URL    | 请求服务的基础地址                 |
| API Key     | 程序调用服务的敏感凭证             |
| Model       | 处理请求的模型名称                 |
| Routing     | 在本地进行协议或请求转发的中间层   |
| Diff        | 修改前后文件的差异                 |
| MCP Server  | 通过 MCP 提供工具或数据的服务      |
| Skill       | 一套可以重复使用的工作流程说明     |
| `AGENTS.md` | 写给 AI 和项目协作者的项目规则文件 |

## 常见 HTTP 错误码

| 错误码      | 通常表示             | 先查什么                    |
| ----------- | -------------------- | --------------------------- |
| 400         | 请求格式不符合要求   | 参数、请求体和协议          |
| 401         | 未通过认证           | API Key、登录状态和前后空格 |
| 403         | 有身份但没有权限     | 账号权限、余额和服务限制    |
| 404         | 地址或资源不存在     | Base URL、路径和模型名      |
| 408/504     | 请求超时             | 网络、服务状态和请求规模    |
| 429         | 请求过多或额度限制   | 频率、余额和服务商限制      |
| 500/502/503 | 服务端或上游暂时异常 | 官方状态、日志和稍后重试    |

错误码只是线索，不是最终结论。请同时保留错误文本、工具版本和操作上下文。

## 两个判断口诀

**先看发生在哪一层**：登录、Key、渠道、模型、项目还是任务。

**一次只改一个变量**：否则即使问题消失，也不知道真正修复了什么。
