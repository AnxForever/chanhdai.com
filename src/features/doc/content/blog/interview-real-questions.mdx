面经看多了会有一种奇怪的熟悉感：不同的人、不同的时间、不同的公司，回来写下的题却高度重合。

RAG 怎么优化、ReAct 怎么跑、MCP 有什么缺点——同一批问题在不同人的面试里反复出现。这说明 AI 应用岗的考点已经收敛了，而这恰好是好消息。

下面这些不是模拟题，是牛客、LeetCode 讨论区、面经站上公开的真实记录。我按公司分组，并且标注问的是哪个岗位——因为同一家公司，不同岗位考的东西可以完全不同。

## 一、先排雷：决定考什么的是 JD 正文，不是公司

最干净的一个例子，是同一家公司（有赞）的两个岗：

| 岗位名       | 面试在考什么                               |
| ------------ | ------------------------------------------ |
| agent 开发   | AI 概念（RAG、Agent、MCP）                 |
| 后端 AI 开发 | 后端八股（线程池 / MySQL 索引 / 分库分表） |

两个岗的考卷完全不一样。所以别按公司名背题，按 JD 正文里的关键词背题。

### 一个容易看漏的地方

注意是**正文**，不是岗位名。

下面小红书那个岗，标题写的是「产品工程师」——光看名字你根本不知道它要考什么。但它的 JD 正文里写着加分项「有 LLM / Agent / RAG 相关项目经历，个人或课外项目均可」。

只看标题会漏掉。

反过来也危险：看到「AI 应用开发」就无脑背 AI 题，也不对——同一个名字下面，有的组考 Agent 架构，有的组考 Spring AI 和 JVM。字节那两小节就是这种情况。

## 二、按公司看真题

### 小红书 · 产品工程师

一面：

- 怎么降低大模型幻觉
- 知识库规模有多大
- RAG 效果不好怎么优化
- RAG 与 Agent 的区别
- Agent 有哪些类型（ReAct）
- 整体架构是怎么设计的
- Tools 是怎么被模型理解的
- 工具之间的编排依赖怎么处理
- 会话记忆怎么实现
- prompt 注入怎么防范

二面：拷打 AI Agent 项目 30 分钟，重点是长会话的记忆存储策略。

手撕：第 K 大元素、环形链表。

### 淘天集团 · AI 应用开发 Agent 岗 · 一面

- RAG 里 BM25 与向量混合检索的结合逻辑与效果
- PDF 扫描件 OCR 与表格结构化提取
- 多智能体 State 管理与 Checkpoint 分配
- 状态竞争怎么处理
- MCP 工具标准化接口设计、出参入参，MCP 的缺点与流式结果
- 主子 Agent 架构
- 单会话 token 量有多少
- Qwen 用的是哪个具体版本
- 子任务失败后的重试 / 降级
- FastAPI + SSE 流式输出
- LangGraph 与 LangChain 的选择理由
- Checkpoint 持久化与断线恢复
- 向量库建索引怎么选型
- RRF 重排序与精排模型

### 阿里 · AI 应用开发 · 一面（14 连问，65 分钟）

- 项目架构与技术栈
- Agent 完整流程：`Request → State/Context → Plan/Route → Tool Call → Observation → Validate → Final`。要能说出最大步数、token / 费用预算、超时这三道闸门
- Agent 怎么优化：用 trace 拆分模型耗时、排队耗时、工具耗时、检索耗时
- 图片、表格这类异构数据怎么处理
- 多轮追问与分批评估怎么做
- 微调 vs RAG 的取舍
- CoT 的提升与局限
- SFT 数据集怎么构建

手撕：合并区间（追问分布式节点上的区间全局合并）。

### 字节跳动 · AI 应用开发 · 一面（60 分钟）

**10 道项目题 + 6 道八股 + 1 道算法。**（先记住这个比例——下面第三节里会出现一个「字节某组不问八股」的记录，两者不矛盾，翻到那里看。）被记下来的：

- Agent 的学术组成（Planning / Memory / Tool Use）
- Agent Memory 怎么设计：短期 Redis、长期向量库、工作记忆放任务状态
- 长会话 prompt 怎么处理：摘要压缩 / 滑动窗口 / 关键信息提取
- 怎么减少幻觉
- Rerank 方案：Cross-Encoder、ColBERT、LLM 排序
- Workflow 的原子性与回滚
- Workflow 与 Agent Loop 的设计取舍
- Spring AI 的优势
- 多租户下的模型热更新

手撕：LRU Cache（并发追问）。

### 群核科技（杭州）

- 项目里用了哪些 AI 工具、具体做了什么
- 提示词经验，以及好提示词的设计维度
- 什么是 MCP、用 MCP 做了哪些工具、`@Tool` 注解的作用

二面：对 AI 的看法、AI 会不会取代程序员。

其他：分库分表、Nginx 反向代理、JWT、ThreadLocal 销毁、Redis zset 的使用理由、线上 OOM 排查。

算法：有效的括号、三数之和、水果成篮、岛屿数量、LeetCode 81、多维 DP。**有面试者因为算法刷题太晚，一面没过。**

### 绿盟科技

一晚速通三面，已 offer。**全程无八股，只问项目**：安全护栏、Agent / MCP / Skill 的区别、提示注入、大模型越狱。

### 上海盛迭 · 前端实习

- 项目难点：双 token 鉴权、前端无感刷新
- WebSocket 的全部知识
- 场景题：AI 对话中语音输入会不会中断、怎么设计中断、AI 对话中断后内容怎么保留
- SSR 底层原理及优化
- 地图上 10000 个标记怎么优化
- 300MB / 200KB 图片的加载进度条怎么设计

### 携程 · 后端 Agent 开发

- 拷打实习经历
- AI coding 工具的使用（Cursor / Codex 怎么提效）
- Java 基础八股：`count++`、String 常量池、三次握手

## 三、有实证的「八股比例低」名单

> 先说限制：这些说法都只是网友自己的单次经历总结，样本只有一个人。它能证明「存在这样的面试」，不能证明「这家公司一定不问八股」。当参考，别当保证。

| 公司 / 团队 | 被记录下来的事实                                                          |
| ----------- | ------------------------------------------------------------------------- |
| 绿盟科技    | 全程无八股，只问项目                                                      |
| 腾讯云 CSIG | 暑期实习全程无八股                                                        |
| 字节某组    | 「我们不问八股，挑一个你写得最爽的代码片段讲讲设计」                      |
| 阿里二面    | 扔一份 GitHub 代码，让你现场找线上 bug                                    |
| 美团        | HR 面前加一轮「项目深度面」，专问项目有没有上线、多少用户、最大的技术挑战 |

### 但等一下，这两条对不上

前面字节写的是「10 道项目题 + 6 道八股」，这里写的是「不问八股」。

同一家公司、不同组、不同招聘季，考卷可以完全不一样。所以别拿任何一份面经当成某家公司的统一标准——它的价值是告诉你「这类题存在」，不是「这题一定有」。

规律不复杂：**越靠近业务的组，越不在乎你背了多少，越在乎你做过什么。**

## 四、把真题压缩成四个必考簇

| 必考簇 | 反复出现的题                                                    |
| ------ | --------------------------------------------------------------- |
| RAG    | 混合检索、Rerank、Chunking、效果优化                            |
| Agent  | ReAct、Memory 设计、Workflow vs Agent Loop、State 与 Checkpoint |
| MCP    | 是什么、怎么用、接口设计、缺点                                  |
| 可靠性 | 重试 / 降级、原子性与回滚、状态竞争                             |

四个簇里出现频率最高的反而不是概念题，而是这一类：**它的缺点是什么？**——MCP 的缺点、CoT 的局限、Workflow 的边界。这类问题没有背诵答案，只能靠你真的用过。

另外别忽略算法：上面的真题里没有一道是竞赛题，全是 Hot 100 量级。

## 五、一句话版本

> 考点已经收敛成四个簇；按 JD 正文里的关键词而不是公司名准备。

## 六、自测

1. 有赞那两个岗位的例子说明了什么？你会怎么判断一个 JD 该用哪套准备？
2. 「八股比例低」名单的最大限制是什么？为什么必须说出来？
3. 四个必考簇分别是什么？哪一类最不可能靠背诵答好？
4. 如果面试官问「MCP 有什么缺点」，你的回答从哪儿切入？
5. 绿盟全程无八股，是不是意味着可以不准备八股？为什么？
